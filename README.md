Toronto Outbreak Tracker (myptv)

&#x09;- A lightweight, canvas-based contagion simulation visualizing a zombie outbreak moving across a procedural street graph of Toronto. Inspired by Particle Tracking Velocimetry (PTV) workflows and built for fun.



Highlights

&#x09;- Graph-Based Mobility: Entities navigate a procedural node network representing Toronto landmarks (York University, U of T, ROM, Eaton Centre, CN Tower) down to Lake Ontario.



Agent Behaviors:



&#x09;- Humans: Wander the grid and dynamically evaluate escape routes away from the nearest threat once zombies breach their panic radius.



&#x09;- Zombies: Spawn continuously from the Lake Ontario portal, transmitting infection upon proximity contact.



&#x09;- PTV Motion Tracing: Real-time trajectory tracing (myptv-style particle trails) tracking historical movement paths of active vectors.



&#x09;- Zero Dependencies: Single-file architecture running vanilla JavaScript and HTML5 Canvas with Tailwind CSS via CDN.
